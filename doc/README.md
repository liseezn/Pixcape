## 项目概览

Pixcape 是一个基于 React、TypeScript、Vite 和 Canvas 2D 的轻量级 64×64 像素画编辑器。当前功能以单画布绘制和 PNG 导出为主。

## 文档维护原则

- 文档应与实际代码和部署配置保持一致。
- 任何新增工具、快捷键或导出格式，都应同步更新使用指南。
- 修改 Docker、Nginx、GitHub Actions 或域名配置时，应同步更新部署文档。
- 对尚未实现的功能应明确标注为计划事项，不要描述为现有能力。
